# Sight — landing

The marketing site for [Sight](https://github.com/mirasawe/Sight), built with
Next.js 16, Tailwind 4 and motion. Monochrome by design.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build
npm run lint
```

The production build is exported as a static site and deployed to GitHub Pages.
See the root [`README.md`](../README.md) for the app itself.
